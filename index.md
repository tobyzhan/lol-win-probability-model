# League of Legends Draft / Ban Analysis

This project predicts the probability of winning a League of Legends match
based on champion picks, bans, and team composition.

## Project Overview

This project analyzes League of Legends draft data to determine how champion
selection and bans affect match outcomes.

## Features

- Champion picks
- Champion bans
- Blue / red side
- Team composition features
